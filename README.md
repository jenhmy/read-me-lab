<h1>
  ReadMeLab
</h1>

**ReadMeLab** is a visual editor that writes Markdown for you. You type and style your text in a simple rich text box, like a basic word processor, and on the right you see the equivalent Markdown in real time, ready to copy or download.

✨ You never type Markdown symbols. Everything comes from the toolbar buttons and from the way you write on the left.

## 🎯 How It Works

- **Left**: an editable box with the real style applied (bold looks bold, a heading looks big), with a toolbar on top.
- **Right**: the resulting Markdown, read-only. It is regenerated every time something changes on the left.
- **Import**: paste an existing Markdown once to convert it into the writing area and keep editing it visually.

The translation goes in one direction only: **from visual to Markdown**.

The output is meant for a README, so every button produces something GitHub can display.

---

## ✨ Main Features

- Bold, italic, strikethrough, inline code, sub and superscript
- Six heading levels, styled the way GitHub draws them
- Bullet, numbered and task lists, with nesting
- Tables with column alignment and centering
- Quotes, horizontal lines and collapsible sections
- Links, images, image galleries and text or image alignment
- Badges, progress bars, technology icons and QR codes
- Animated typing text and wave banners
- GitHub profile cards: visitor counter, activity graph and commit streak
- Table of contents generated from your headings
- Symbols and emoji pickers
- Sample document that uses every feature
- Copy, download as `.md`, import, undo and redo
- Responsive navigation

## 🔒 Privacy

Everything runs in your browser. There is no backend and nothing is stored. The GitHub username asked by some cards only lives in memory while the page is open, and only appears in the URL of the image you insert.
